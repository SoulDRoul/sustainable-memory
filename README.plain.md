# 可持续记忆 · 大白话简版

[中文](README.md) | [大白话（简版）](README.plain.md) | [English（概览）](README.en.md)

> 这是同一份说明的简版，三分钟读完。细节在 [中文版](README.md)；两边冲突时，以中文版为准。
> 想看它长什么样：[五分钟演示](演示.md)。

## 一句话

每次新开对话，它都不记得上一轮说过什么——像每天早上醒来，失忆一次。

这套东西只做一件事：把你要它记住的事写进几份文本文件，下次开场先读它们，再接话。
所以你说过的“这条别再提”，下一次它还看得见。

看得见，不等于一定照做——它只保证那句话没丢，不保证它每次都会听。

## 给谁

- 跟 AI 长期聊同一件事、每次都得从头解释的人。
- 愿意每轮花五分钟写几句话的人。
- 在意“我说过不要什么”，不只是“我说过什么”的人。

## 不给谁

- 想开箱即用、零维护的人。
- 想要一个永远答应的助手的人。
- 指望它自己变聪明的人。

## 三份文件

放在一个文件夹里，都是纯文本；内容你定，字它可以代抄：

- **当前状态**（便签）：现在在做什么。一个项目三行：状态 / 原因 / 下一步。
- **否决清单**（黑名单）：以后别再提的事。一句话一条，抄你的原话，标上出处。
- **交接笔记**（交接本）：每次聊完一页——这次到哪 / 下次从哪接 / 有没有新否掉的。
- **留言**（可选）：唯一一份“写了不必读”的，想写就写。

它不做自动摘要，也不建向量库。摘要会把你明确说过“不”的事抹平，错了还没人知道；
这几份是明文的，谁都能打开看。

## 两个动作

- **收尾**：聊完写一页交接本（它起草、你改），更新便签，再把否决清单的“覆盖至”
  推到这一页——就是记下“我读到这儿了”，下次从这之后接。
- **回忆**：下次开场，先读便签、否决清单、最后一页交接本，再回答。

不做收尾，这一轮对下一次等于没发生；不做回忆，它从零开始。

## 平时怎么改它

它不会读心。它写错了，你指到那一句，说清为什么；它记下来，下次改。

不需要会写提示词，也不需要什么“沟通技巧”——三样就够：指到句子、给出理由、说清什么情况下你会改主意。

实在说不出理由，就说“我觉得不对，但说不上来”——它不压掉这句话，会和你一起找依据。

## 你要付出什么

- 每轮五分钟：看它写的、改、给判断。这是最容易放弃的一步，先想清楚。
- “别再提”要你自己写。它不会替你判断该否什么。
- 备份：记忆文件没了就是没了，每月拷一块硬盘。

## 怎么知道它在工作

过一周，问三个问题：

- 哪件事是我明确说“别再提”的？
- 上一个决定是什么，为什么那么定？
- 上一次被指出错在哪，后来怎么改的？

三个都答得出，它在工作；答不出，说明文件在，判断没进去。

## 常见误会

- 它不是记忆插件，查找不会更快。
- 它不保证照做：否决得真的被读进上下文才算数。
- 它不让模型变聪明；换模型，行为也不一样。
- 它不替你做判断，只保证痕迹不丢。
- 默认一个人用；两个人同时写会打架。
- 它不承诺造出生命，也不承诺“更像人”。
- 它不会自己发现错误。错要你指出来；它负责记住，不再丢、不再犯。
- 它不是全自动：判断得你来。也不是全手动：字它能代笔。

## 只做一件事的话

只维护否决清单。每次说“这条以后别再提”，它抄进去；下次先读这一栏。
这是整套东西里最值钱的一块。
